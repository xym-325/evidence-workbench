    📖 使用说明 / 名词解释 / 常见问题

    有疑问就点开对应的一条，无需全看。
    ① 这个工作台能做什么？
    把"一句临床问题"变成"一份可信的证据综述"：检索式 → 检索筛选 → 逐条核验引用真假 → 精读，保留检索与筛选记录；断网时可查看已保存案例。
    ② 四个步骤分别在做什么？
    1. 检索式生成：拆概念、匹配官方 MeSH 词、拼检索式；不确定的标「待核」，绝不编造。可勾选概念、查命中数、自动调优。
    2. 检索·筛选·综述：按纳入/排除标准筛选，生成结构化综述与 PRISMA 流程图。
    3. 引用核验：参考文献逐条查 Crossref/PubMed，报告「匹配/题录冲突/未检出/暂无法核验」，保留原始依据。
    4. 精读引擎：用 SQ3R 对关键文献做证据锚定的精读。
    ③ 名词解释
    • MeSH：PubMed 官方医学主题词表。
    • 待核：未在官方词表精确命中，仅作自由词，需人工确认。
    • PICO：P 人群 / I 干预 / C 对照 / O 结局。
    • PRISMA：系统评价报告规范，其流程图记录检索到纳入的过程。
    • endotype（内型）：按分子机制划分的疾病亚型。
    • SQ3R：Survey–Question–Read–Recite–Review 五步精读法。
    • DOI：文献"身份证号"；核验就是拿它查是否真实存在。
    ④ 常见问题
    • 检索式 0 命中？ 概念太多，取消勾选泛化词或点「自动调优」。
    • 断网能用吗？ 断网时可查看已保存的真实案例；新的检索与外部题录核验需要联网。
    • 能核验自己的文献吗？ 能，第 3 步粘贴题录 / DOI 列表 / BibTeX。
    • 结果能导出吗？ 综述导出 Markdown/Word/RIS，PRISMA 图导出 PNG。
    • 数据可靠吗？ 来源 NLM MeSH / OpenAlex / Semantic Scholar / Crossref / PubMed，仅供科研参考，不替代临床决策。
    ⑤ 如何选择数据库？
    • PubMed：生物医学首选，有 MeSH 主题词，查全查准。
    • Web of Science：跨学科 + 引文分析（找研究脉络）。
    • Embase：药物 / 器械 / 会议摘要强。
    • Scopus：覆盖广，工程与计算机类 AI 期刊多。
    • Cochrane：系统评价 / 循证医学证据。
    • CNKI / 万方：中文文献（需机构权限）。

    本工作台用 MeSH + PubMed 生成检索式，并可在第 1 步「多库检索式」把检索式翻译到其它库。

    🔌 开发者：API 接口（可被医院系统 / 科研平台二次集成）

    本工作台是可本地部署的 REST 服务，接口如下：

    • POST /api/run 一键全流程 {pico, online}
    • POST /api/mesh 生成 MeSH 检索式 {pico}
    • POST /api/count 查 PubMed 命中数 {query}
    • POST /api/tune 自动调优检索式 {items}
    • POST /api/review 检索·筛选·综述 {task_yaml}
    • POST /api/verify 引用核验 {refs, online}
    • GET /api/health 组件自检

    示例：

    curl -X POST http://127.0.0.1:8130/api/run -H "Content-Type: application/json" -d "{\"online\":false}"

    可私有化部署于内网，外部检索会向数据库发送检索式，AI整理会向模型服务发送所选题录与摘要；不应上传患者资料。账号体系与多用户为产品化阶段规划。
